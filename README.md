# MasterBook 8.0 — финальный MVP

Telegram Mini App для мастеров и небольших сервисных команд.

## Что внутри
- Клиенты: создание, редактирование, удаление, телефон, адрес, сумма работ.
- Работы: цена, расходы, чистая прибыль, дата, адрес, статус, оплата, комментарий.
- Расходы: отдельный учёт затрат.
- Дашборд: доход, расходы, прибыль, клиенты, работы, неоплаченные работы.
- Периоды: всё время / последние 30 дней / последние 7 дней.
- Поиск по работам, клиентам и расходам.
- CSV-экспорт.
- JSON-резервная копия.
- Telegram Mini App initData HMAC-проверка.
- Изоляция данных по Telegram user ID.
- SQLite с индексами и WAL; для продакшена с реальными клиентами рекомендуется PostgreSQL или постоянный диск.

## Переменные окружения
- `BOT_TOKEN` — токен бота от BotFather.
- `WEBAPP_URL` — публичный HTTPS URL приложения.
- `DB_PATH` — необязательно; путь к SQLite-файлу.
- `DEMO_MODE=1` — только для локального демо без Telegram auth. Не использовать для реальных данных.

## Запуск Web/API
```bash
pip install -r requirements.txt
uvicorn app:app --host 0.0.0.0 --port $PORT
```

## Запуск бота
Бот запускается отдельным процессом:
```bash
python bot.py
```

## Важно для продакшена
1. Не хранить `BOT_TOKEN` в GitHub.
2. Использовать HTTPS для `WEBAPP_URL`.
3. Для постоянных данных использовать PostgreSQL или постоянный диск.
4. Для бота нужен хостинг, который не усыпляет процесс polling.
5. Перед продажей подключить платежи/подписку и админ-панель.
